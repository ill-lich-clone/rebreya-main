# BG3 Hotbar 3.4.9: один рендер портрета на обновление Actor

На двух флагах хода портрет текущего актёра собирался четыре раза; теперь два раза. Фильтр слотов, пассивы, смена привязки токена, очистка предметов, GM/player policy и удалённые BG3 flags сохранены. `portrait-update.test.mjs` исполняет обработчик из установленного файла; из него же берётся исходник для обратимого патча.

`manifest.json` содержит backup исходной установленной версии 3.4.8 и SHA-256 каждого изменённого файла. Патч `patches/bg3-inspired-hotbar.patch` применяется из каталога, содержащего sibling `bg3-inspired-hotbar`: `git -c core.autocrlf=false apply --check <patch>`, затем `git -c core.autocrlf=false apply <patch>`. Для отката сначала `--reverse --check`, затем `--reverse`. Прямое и обратное применение проверены побайтово на копии. Сохранены старые точки входа; новая загружает весь граф BG3 с URL версии 3.4.9, совместимой с динамическими импортами Rebreya.
