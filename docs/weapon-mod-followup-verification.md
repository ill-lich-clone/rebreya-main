## Native UI

Foundry13.351, dnd5e5.2.5, MIDI13.0.61, браузерный пользователь CODEX с правами GM. Проверялся штатный ItemSheet5e реальной аркебузы. Для шести креплений винтовки и двух арбалетных креплений использованы временные Actor Documents только в памяти: `game.actors.has(id) === false`. Эти окна закрыты после проверки. Листы шириной440/820px дали квадратные карточки внутри диаграммы, без пересечений; у арбалета блока модернизации нет. В основной панели чертёж513×307.8px. В каталоге нет горизонтального переполнения. Консоль после последней загрузки: ошибок нет.

Ссылки используют штатный `a[data-link][data-uuid]`: успешный щелчок подтверждён `doc.sheet.rendered === true`. Missing source не создаётся; если у пользователя нет доступного Item, остаётся обычное имя. Native шаблонный PLAY mode отключает обычные button, поэтому кнопки навигации используют штатный класс always-interactive. Оба найденных в live QA дефекта сначала воспроизведены отдельными RED assertions, затем исправлены.

Фактические файлы и CSS1.4.390 загружены. Работающий сервер Foundry сохраняет metadata manifest1.4.389 до штатного обновления сервера; сервер активной игры не перезапускался. Выпускаемый module.json и versioned entrypoint имеют1.4.390.

Платная пересборка проверена на fixture через настоящий сервис, а не на кошельке действующего персонажа. В наблюдаемом инвентаре нет модернизированных частей: native список корректно показывает пустую owned группу и запрещает установку отсутствующего. Реальные Actor Items/кошельки/патроны не изменялись вручную; атакующие броски не отправлялись. Автоматические исходные проекции модуля и действия других подключённых пользователей не подменялись.
