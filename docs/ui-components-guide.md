# UI Mini Guide (Inventory / Party)

Этот гайд фиксирует базовые правила формы и состояний для партийного инвентаря.

## Радиусы и форма

| Элемент | Класс/роль | Радиус |
|---|---|---|
| Главное окно / верхний хедер | `.panel` (header-level) | `12px` |
| Крупные секции | `.panel`, `.section` | `8px` |
| Строки списков (предметы/участники) | `.row` | `6px` |
| Поля ввода/поиска | `input`, `select`, `textarea` | `6px` |
| Малые кнопки действий | `.button`, `.rm-button--small` | `7px` |
| Бейджи статусов | `.badge` | `999px` |
| Вкладки навигации | `.tab` | `8px 8px 0 0` |

## Семантические классы

- `.panel`: основная рабочая зона с явной границей и фоном.
- `.section`: вторичная секция внутри панели.
- `.row`: строка данных (предмет, участник).
- `.badge`: короткий статус (СИЛ, Груз, Энергия, фильтр).
- `.tab`: навигационная вкладка, не визуально как обычная кнопка.
- `.button`: действие пользователя.

## Состояния

- `.danger`: критическая проблема (перегруз, нулевые запасы).
- `.warning`: предупреждение (низкие запасы, риски).
- `.muted`: служебный или вторичный текст.
- Активное состояние (`is-active`) всегда должно быть заметнее неактивного.

## Правила иерархии

1. Критические ресурсы (груз/еда/вода/энергия) видны сразу.
2. Активная вкладка должна считываться за долю секунды.
3. Обычные строки без тяжёлых рамок; акцент только на hover/open/critical.
4. Pill-форма используется только для коротких статусов и компактных фильтров.
