# UI Redesign Plan

Цель: привести окна Rebreya к уровню аккуратных Foundry-модулей: меньше шума, ясные главные действия, постоянный доступ к настройкам и предсказуемые списки данных.

## P0. Безопасный фундамент

- Зафиксировать общий каркас окон: `.rm-app-shell`, `.rm-app-header`, `.rm-app-sidebar`, `.rm-app-main`, `.rm-app-settings-drawer`.
- Все новые классы только с префиксом `rm-*`; голые `.panel`, `.row`, `.button` и похожие имена не использовать в шаблонах.
- Палитра задаётся через токены `:root`, чтобы окна можно было перекрашивать системно, а не точечно.
- Новые UI-паттерны сначала внедрять на одном окне, затем переносить на экономику и инвентарь.
- Не трогать механику расчётов при визуальном переносе окна.
- Не добавлять новые брейкпоинты без отдельной задачи.

## Палитра

- База: тёмный графит и тёплая латунь вместо плоского коричневого.
- Акцент: яркая латунь для главных действий.
- Второй акцент: бирюзовый для интерактивных/drag-состояний.
- Состояния:
  - danger: красно-коралловый;
  - warning: янтарный;
  - success: живой зелёный;
  - disabled: приглушённый серо-бежевый.

## Порядок переноса

1. Лутген: компактный генератор с результатом справа и настройками в drawer.
2. Экономика: обзор + фильтры + список городов + боковая панель инструментов.
3. Партийный инвентарь: склад/группа/крафт на новом shell после проверки паттерна на лутгене.
4. Остальные окна: город, связи, государства, глобальные ивенты.

## Лутген v2

- Главное действие: `Сгенерировать`.
- Второе главное действие после результата: `Отправить в чат`.
- Дополнительные источники и проценты магии лежат в `Настройки генерации`.
- Чат-карточка содержит реальные draggable-предметы.
- После перетаскивания предмета в лист персонажа строка помечается забранной в чате и удаляется из открытого результата лутгена.
- Монеты забираются отдельной кнопкой в чат-карточке.
