# Промт для Codex: автоматизация рас Тейванкаля V0.1

Скопируй текст ниже целиком и используй как задачу для Codex.

```text
Ты работаешь в общем Git-репозитории, где код меняют несколько человек.

Обязательный протокол перед любыми правками:
1) Выполни `git status --porcelain=v1 -b`.
2) Проверь текущую ветку (`git branch --show-current`).
3) Выполни `git fetch origin --prune` и проверь актуальность `origin/main` (или `origin/master`, если он есть).
4) Если есть чужие незакоммиченные изменения или конфликт с актуальной основной веткой, остановись и сообщи.

Работай только в ветке `lich_branch`.
Никогда не коммить и не пушь в `main/master`.
Не используй `force push`.

Цель:
Автоматизировать КАЖДУЮ расу из файла `Расы Тейванкаля V0.1.txt` для Foundry VTT (dnd5e) в этом модуле.

Что считать автоматизацией:
- Любые игромеханические эффекты, которые можно выразить через MIDI-QoL, DAE и/или DFreds Convenient Effects.
- Изменения базовых параметров персонажа: КД, хиты (текущие/максимум), скорость (walk/fly/swim/climb/burrow), чувства, сопротивления/иммунитеты/уязвимости, спасброски, проверки навыков, владения.
- Активные особенности: действия, бонусные действия, реакции, особые действия, проверки/спасброски/урон/лечение.
- Ограничения использований: N/день, от характеристики, от бонуса мастерства, восстановление на коротком/долгом отдыхе.

Правила принятия решений:
- Если механику можно перенести в `Active Effect` или `Activity`, переноси.
- Если механика частично автоматизируется, сделай автоматизируемую часть и добавь явный manual-note для оставшейся логики.
- Не оставляй без разбора ни одну расовую особенность/подособенность.

Что обновить в проекте:
1) `data/races-teyvankal-v01.json`
   - Добавь/обнови структурированные данные автоматизации для каждой расы и каждого умения/опции.
2) `scripts/data/races-compendium.js`
   - Используй новые поля автоматизации при сборке race/feat документов.
   - Заполняй `effects`, `activities`, `uses`, `flags` и связанные поля dnd5e.
3) При необходимости добавь/обнови утилиту в `tools/` для повторяемой генерации автоматизации из текста.
4) Создай отчёт покрытия в `docs/`:
   - Полностью автоматизировано
   - Частично автоматизировано (с причиной, что осталось вручную)
   - Оставлено вручную (с причиной)

Требования к результату:
- Каждая раса из `Расы Тейванкаля V0.1.txt` обработана.
- Для каждой особенности есть явный статус: full/partial/manual.
- Для активных умений с уроном/лечением/использованиями созданы соответствующие `activities` и/или `effects`.
- Все изменения детерминированы и воспроизводимы.

Проверки перед завершением:
1) Покажи `git diff --stat` и кратко объясни, что изменено.
2) Выполни доступные проверки (минимум — валидация JSON и синтаксиса изменённых JS-файлов).
3) Сделай осмысленный commit.
4) Запушь ветку `lich_branch` в `origin`.
5) В ответе дай краткий отчёт: что автоматизировано, что частично, что вручную.
```
