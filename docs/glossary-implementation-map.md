# Глоссарий Rebreya: карта реализации

Дата сверки: 12 мая 2026.

Этот документ фиксирует, какие разделы из `Глоссарий.pdf` требуют механической автоматизации в модуле, а какие должны идти в журналы/справку.

## 1) Механика (код)

1. Огнестрельные атаки как отдельный тип атаки.
2. Специальные свойства атак (`МКУ`, `МУ`, `РКУ`, `Наскок`, `Смертельное`, `Отравляющее`, и т.д.).
3. Кастомные боевые действия (`Обезоруживание`, `Провоцировать`, `Прорубать`, `Ловкость рук`, `Украсть`, `Ремонтировать`, `Написать`, `Нарисовать`).
4. Кастомные реакции (`Провоцированные атаки ⚡`, `Опознание заклинания ⚡`, `Ухватиться за уступ ⚡`, `Схватить предмет ⚡`, `Парирование ⚡`, `Перехват ⚡`).
5. Кастомные состояния/статусы из блока `[Lich]`, включая статусы со значением.
6. Ауры (вход в ауру, начало хода в ауре, 1 срабатывание урона за раунд).
7. Пошаговые эффекты состояний (пример: `Затихающий урон` на старте хода).

## 2) Контент (журналы)

1. Базовые правила и пояснения (владения, проверки, преимущество/помеха, примеры).
2. Табличные разделы (`Сл`, модификаторы, ранги, размеры, урбанизация, торговые запасы и т.д.).
3. Текстовые описания состояний/аур как справка для игроков.
4. Все PHB/PHB+ разделы, которые не меняют поведение через код.
