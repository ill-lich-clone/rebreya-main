# Общая десятиминутная сцена (R10)

## Границы и владельцы

Только выбор и описание занятия. Никаких shortRest, rollHitDie, HP/HD/uses, календаря или реального countdown. Public intentions не содержат скрытых Item/GM notes. Единственный owner состояния — SceneActivityService через существующий WorldSettingMutationRepository; composition root scripts/main.js. Полноэкранное окно и локальный контроллер подключены; native multiplayer приёмка отмечается отдельно.

## Правила — scripts/data/scene-activity-rules.js

- SCENE_ACTIVITY_ACTIONS: inspect/help/prepare/rest/custom и русские названия. SceneActivityError(code) даёт стабильный код и понятное сообщение.
- sceneActivityExactKeys(value,keys), validateSceneActivityIntent(kind,intent) проверяют exact payload и возвращают detached copy. Start: operationId/groupActorId/expectedGroupRevision/initiatingActorUuid/participantActorUuids/durationMinutes10. Choose: operationId/sessionId/actorUuid/actionId/text/expectedRevision. Finish: operationId/sessionId/expectedRevision/status completed|cancelled; status добавляет доверенный route. ID1–128, до64 уникальных приглашённых Actor UUID, text0–500 UTF-16 units; custom требует непустой trimmed text. Имена/текст выводятся как literal text, не HTML.
- normalizeSceneActivityState(raw) → {version:1,activeByGroup,groupRevisions,history,recentOperations}. Null/empty default; повреждённое/неизвестное состояние отклоняется, не сбрасывается. Private validChoice/validSession/validResult проверяют сохранённые поля и ссылки участников. Envelope содержит не более64 terminal sessions/256 receipts, groupRevisions не вытесняется.
- startSceneActivity(state,intent,context), chooseSceneActivity(state,intent,context), finishSceneActivity(state,intent,context) → {state,result}. Чистые reducers; context включает authenticated senderId/isGM, живые groupMemberActorUuids/ownedActorUuids, injected now/createSessionId. Start/terminal повышают groupRevision; каждый новый выбор/terminal повышает sessionRevision. Одна active session на группу. Инициатор не может быть своим дополнительным участником; участник должен оставаться в группе и владеть выбранным Actor (либо быть GM).
- sceneActivityFingerprint(kind,intent,senderId) — SHA-256 canonical sorted-key exact intent, включая operationId и sender. Private authenticate/retry/openSession/nextRevision/outcome/commit ведут permissions, bounds и receipts. Exact retry возвращает прежний outcome (changed=false/replayed=true) до проверки устаревшей revision. Изменённый request или sender с прежним operationId отклоняется. Новый noop выбора не пишет receipt/state; старый expectedRevision защищает от повторного применения после чужой заявки.
- projectSceneActivityForUser(state,context) → {groupActorId,groupRevision,session|null}. Только open session для GM/владельца занятого или приглашённого Actor; selectableActorUuids содержат лишь разрешённые дополнительные действия. Инициатор видит сцену без автоматической второй заявки. Не возвращает history/receipts.

## Application — scripts/application/scene-activity-service.js

- SceneActivityService({repository,resolveContext,refresh}) использует SCENE_ACTIVITY_SETTING=sceneActivityState. start/choose/finish/cancel(intent,sender) вызывают один private #transition; #terminal устанавливает status по методу, extra payload отвергается. #groupFor разрешает group из start intent либо сохранённой session/receipt.
- #transition внутри одной repository.mutateObject заново читает state, живые membership/ownership, применяет reducer и сохраняет transition+receipt одной записью. shouldCommit отключает duplicate/noop writes. Repository guard проверяет active GM непосредственно перед и после записи; дополнительной world queue нет. При write error readback принимает только exact fingerprint/sender/result запланированной записи; неизвестный outcome возвращает исходную ошибку без повторного start. refresh передаёт только group/session/revision references; ошибка проекции не откатывает committed transition.
- getSnapshot({groupActorId,viewer}) заново авторизует viewer и возвращает projection, canManage/groupName и список имён членов группы. Только публичные намерения; никаких actor resources.

## Commands, composition, settings

- scripts/infrastructure/foundry/scene-activity-command-contract.js: SCENE_ACTIVITY_COMMANDS start/choose/finish/cancel. isValidSceneActivityPayload(action,payload) проверяет exact wire поля; domainIntent добавляет terminal status. authorizeSceneActivity проверяет настоящий authenticated User; start/finish/cancel GM-only, choose ownership дополнительно проверяется внутри queued service. sceneActivityTransportId включает hashed sender+intent и не позволяет gateway replay скрыть изменённый request с прежним durable operationId.
- RebreyaMainModule.#resolveSceneActivityContext({groupActorId,sender}) использует existing managed group registry/getGroupMemberActors/actorIsOwnedByUser; отдаёт имена/UUID и injected timestamp/session ID. #requestSceneActivity вызывает существующий privilegedMutationGateway.mutate. Public startSceneActivity, chooseSceneActivity, finishSceneActivity, cancelSceneActivity и getSceneActivitySnapshot({groupActorId?}) добавлены; default group — текущая. openSceneActivityApp и refresh controller описаны ниже.
- SETTINGS_KEYS.SCENE_ACTIVITY_STATE и registerSettings: hidden world Object с v1 default. Foundry синхронизирует setting; onChange вызывает optional refreshSceneActivityApps, который перечитывает snapshot через публичный API. Никакого raw socket и произвольного кода в уведомлениях. Settings import имеет cache version271.

## UI и lifecycle (1.4.272)

- Composition владеет sceneActivityApps Map<sessionId,app> (setup:<groupId> для формы GM). listSceneActivityGroups() возвращает только доступные текущему User managed группы через existing permission resolver. #getSceneActivityController() однократно lazy-loads SceneActivityController/SceneActivityApp, injects registry/api/factory/indicator; rejected import сбрасывает promise для нового явного вызова. refreshSceneActivityApps({duringReady=false}) работает после game.ready либо с duringReady:true из ready-hook после initialize: Foundry выставляет game.ready позже самого hook, openSceneActivityApp({groupActorId?,sessionId?}) выбирает current group либо первую доступную и возвращает ту же app.
- SceneActivityController({api,registry,createApp,onChange}) — локальная проекция. refresh() читает группы/snapshots, #applyBatch(request,groups,outcomes) последовательно применяет render/close через локальную applyQueue, отбрасывает запоздавшие batch и старые group/session revisions; при revoked access закрывает соответствующие app, terminal не восстанавливается старым ответом. #accept/#ensure/#remove ведут ровно одну app/session. open() поднимает существующую instance, GM-only setup; changed() обновляет индикатор. onClosed удаляет registry entry только если там всё ещё та же app.
- SceneActivityApp(api,snapshot,{onClosed,onVisibilityChange}) — один ApplicationV2 для setup либо active session. _prepareContext строит escaped HBS context, роли, карточки inspect/help/prepare/rest/custom, участников и текущие заявки. setDraft/#draft сохраняют ввод по Actor UUID. applySnapshot сохраняет draft; при обычном peer update #syncReadonly меняет только текст заявок/статус и значения controls без замены DOM или потери focus. Изменившиеся permissions/members вызывают полный render и выбор только разрешённого Actor.
- #request(action,fields) держит original operationId/revision при transport retry. При stale/conflict сохраняет текст, перечитывает snapshot и ждёт следующего явного submit с новой revision. submitChoice/start/finish используют только public API; finish("cancel") вызывает отдельный cancel route. Во время запроса controls disabled; ни одного прямого settings/Actor/resource write.
- reopen/close/dispose: X и «Вернуться к карте» сворачивают локальную active app; setup закрывается. dispose после terminal/permission loss физически закрывает окно и отменяет listeners, late render не оставляет ghost overlay. _onRender использует AbortController и delegated input/change/click, обновляет выбранный Actor/setup participants и текст. renderSceneActivityIndicator(apps) создаёт компактные кнопки возврата к той же instance; DOM textContent и scoped listeners, без world state.
- templates/scene-activity-app.hbs имеет внешнюю обёртку для root PART (Foundry удаляет её при вставке); сохраняемый внутренний section владеет layout/styles. Radios scoped по sessionId, все имена/free text экранируются. styles/main.css: весь viewport через CSS, scroll body/roster, видимый footer, keyboard focus и narrow layout; browser fullscreen и смена active Scene не используются.
- Existing buildToolsRecord() добавляет GM-only «Открыть сцену» с order45; array/record compatibility сохранена. Existing registerSceneControlsHook() обновляет локальные projections на canvasReady/updateUser/deleteActor и изменениях ownership/group members. Ready и native Socket.IO connect перечитывают snapshot; Settings onChange передаёт invalidation, не исполняемый код. Initial UI refresh failure не прерывает initialization/version notice.

Focused UI: scene-activity-app/controller (draft, exact retry/stale, collapse/reopen, terminal during render, replacement, out-of-order, membership revoke), bg3-hotbar-compat (GM tool, array/record), backend/actual gateway regressions. Полный native GM/player/reconnect/GM-switch matrix всё ещё должен быть проверен отдельно.
