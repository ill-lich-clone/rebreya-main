# Общая десятиминутная сцена (R10)

## Границы и владельцы

Только выбор и описание занятия. Никаких shortRest, rollHitDie, HP/HD/uses, календаря или реального countdown. Public intentions не содержат скрытых Item/GM notes. Единственный owner состояния — SceneActivityService через существующий WorldSettingMutationRepository; composition root scripts/main.js. UI этап пока не подключён.

## Правила — scripts/data/scene-activity-rules.js

- SCENE_ACTIVITY_ACTIONS: inspect/help/prepare/rest/custom и русские названия. SceneActivityError(code) даёт стабильный код и понятное сообщение.
- sceneActivityExactKeys(value,keys), validateSceneActivityIntent(kind,intent) проверяют exact payload и возвращают detached copy. Start: operationId/groupActorId/expectedGroupRevision/initiatingActorUuid/participantActorUuids/durationMinutes10. Choose: operationId/sessionId/actorUuid/actionId/text/expectedRevision. Finish: operationId/sessionId/expectedRevision/status completed|cancelled; status добавляет доверенный route. ID1–128, до64 уникальных приглашённых Actor UUID, text0–500 UTF-16 units; custom требует непустой trimmed text. Имена/текст выводятся как literal text, не HTML.
- normalizeSceneActivityState(raw) → {version:1,activeByGroup,groupRevisions,history,recentOperations}. Null/empty default; повреждённое/неизвестное состояние отклоняется, не сбрасывается. Private validChoice/validSession/validResult проверяют сохранённые поля и ссылки участников. Envelope содержит не более64 terminal sessions/256 receipts, groupRevisions не вытесняется.
- startSceneActivity(state,intent,context), chooseSceneActivity(state,intent,context), finishSceneActivity(state,intent,context) → {state,result}. Чистые reducers; context включает authenticated senderId/isGM, живые groupMemberActorUuids/ownedActorUuids, injected now/createSessionId. Start/terminal повышают groupRevision; каждый новый выбор/terminal повышает sessionRevision. Одна active session на группу. Инициатор не может быть своим дополнительным участником; участник должен оставаться в группе и владеть выбранным Actor (либо быть GM).
- sceneActivityFingerprint(kind,intent,senderId) — SHA-256 canonical sorted-key exact intent, включая operationId и sender. Private authenticate/retry/openSession/nextRevision/outcome/commit ведут permissions, bounds и receipts. Exact retry возвращает прежний outcome (changed=false/replayed=true) до проверки устаревшей revision. Изменённый request или sender с прежним operationId отклоняется. Новый noop выбора не пишет receipt/state; старый expectedRevision защищает от повторного применения после чужой заявки.
- projectSceneActivityForUser(state,context) → {groupActorId,groupRevision,session|null}. Только open session для GM/владельца занятого или приглашённого Actor; selectableActorUuids содержат лишь разрешённые дополнительные действия. Инициатор видит сцену без автоматической второй заявки. Не возвращает history/receipts.

## Application — scripts/application/scene-activity-service.js

- SceneActivityService({repository,resolveContext,refresh}) использует SCENE_ACTIVITY_SETTING=sceneActivityState. start/choose/finish/cancel(intent,sender) вызывают один private #transition; #terminal устанавливает status по методу, extra payload отвергается. #groupFor разрешает group из start intent либо сохранённой session/receipt.
- #transition внутри одной repository.mutateObject заново читает state, живые membership/ownership, применяет reducer и сохраняет transition+receipt одной записью. shouldCommit отключает duplicate/noop writes. Repository guard проверяет active GM непосредственно перед и после записи; дополнительной world queue нет. При write error readback принимает только exact fingerprint/sender/result запланированной записи; неизвестный outcome возвращает исходную ошибку без повторного start. refresh передаёт только group/session/revision references; ошибка проекции не откатывает committed transition.
- getSnapshot({groupActorId,viewer}) заново авторизует viewer и возвращает projection, canManage/groupName и список имён членов группы. Только публичные намерения; никаких actor resources.

## Commands, composition, settings

- scripts/infrastructure/foundry/scene-activity-command-contract.js: SCENE_ACTIVITY_COMMANDS start/choose/finish/cancel. isValidSceneActivityPayload(action,payload) проверяет exact wire поля; domainIntent добавляет terminal status. authorizeSceneActivity проверяет настоящий authenticated User; start/finish/cancel GM-only, choose ownership дополнительно проверяется внутри queued service. sceneActivityTransportId включает hashed sender+intent и не позволяет gateway replay скрыть изменённый request с прежним durable operationId.
- RebreyaMainModule.#resolveSceneActivityContext({groupActorId,sender}) использует existing managed group registry/getGroupMemberActors/actorIsOwnedByUser; отдаёт имена/UUID и injected timestamp/session ID. #requestSceneActivity вызывает существующий privilegedMutationGateway.mutate. Public startSceneActivity, chooseSceneActivity, finishSceneActivity, cancelSceneActivity и getSceneActivitySnapshot({groupActorId?}) добавлены; default group — текущая. UI openSceneActivityApp и refresh controller относятся к следующему этапу.
- SETTINGS_KEYS.SCENE_ACTIVITY_STATE и registerSettings: hidden world Object с v1 default. Foundry синхронизирует setting; onChange вызывает optional refreshSceneActivityApps, который перечитает snapshot в UI этапе. Никакого raw socket и произвольного кода в уведомлениях. Settings import имеет cache version271.
