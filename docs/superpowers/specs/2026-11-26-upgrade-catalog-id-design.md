# Сопоставление усовершенствований по ID снаряжения

Штатно импортированная «Шипастая отделка доспеха» устанавливается на совместимый доспех со свободным слотом. Это действует для копий с нормализованным ID и для старых копий с исходным каталожным ID. Предметы сохраняют свой gearId и профиль. Каталог сохраняет исходный productId для правил, цены и автоматизации.

Сопоставление допускает однозначный нормализованный ID из каталога снаряжения. Отличающийся пользовательский профиль по-прежнему отклоняется, как и несовместимый предмет. Эффект отделки остаётся ручным. Условия совместимости остальных усовершенствований и tooltip dnd5e вне этой правки.
