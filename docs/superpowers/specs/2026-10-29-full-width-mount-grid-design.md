# Ширина дополнительных креплений

Дополнительные места под чертежом равномерно заполняют всю доступную ширину при любом количестве мест. В полном ряду три одинаковых квадратных места; неполный ряд распределяется по ширине. При изменении размера окна места остаются внутри панели. Меняется только расположение, количество и поведение мест, установка, перетаскивание и сохранённые данные остаются прежними.
