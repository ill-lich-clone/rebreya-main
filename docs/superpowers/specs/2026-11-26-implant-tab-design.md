# Списки имплантов на листе персонажа

На вкладке «Модифицирование» сохраняется счётчик очков. Ниже идут «Установленные» и «Доступные к установке». Каждая строка показывает имя существующего предмета. Нажатие открывает этот предмет в Foundry. Пустые списки получают короткую подпись.

Вкладка берёт предметы из снимка ImplantService. Этот вариант сохраняет импланты из вложенных контейнеров и устраняет наследование колонок инвентаря. Фильтрация секций инвентаря оставляла бы зависимость от его группировки и пропускала вложенные предметы.

Доступные варианты принадлежат персонажу, ещё не установлены, имеют стоимость установки и хотя бы один доступный экземпляр. Совместимость допускает объединение. Минимальная стоимость должна укладываться в общий лимит персонажа, поскольку на продолжительном отдыхе можно сменить весь набор. Счётчик, правила совместимости, траты очков, количество экземпляров и установка на отдыхе остаются за существующим сервисом. Формат Item, публичный API и остальные вкладки сохраняются.
