# Сходство магических спрайтов с текущими иконками

При размещении магического предмета на сцене его вид сверху сохраняет узнаваемые силуэт, цвета, материал и детали актуальной иконки с маркером. Источником служит именно рисунок актуального набора Foundry. Для генерации можно взять исходник этого же рисунка до наложения маркера. Прежние именные иконки из `templates/icons/Magic Items` исключены из сравнения и генерации.

Обновляем 528 спрайтов с заметными расхождениями по результатам визуальной сверки, включая цвет, материал, орнамент и форму. У 138 похожих спрайтов сохраняем исходные файлы побайтно. Сохранённый компендиум `testovyj3` подтверждает 666 ссылок на актуальные иконки с маркерами из сборки `86935bcc1a32b3e9`. Магические гримуары и флаконы с кровью +1–+3 ссылаются только на старые именные иконки, поэтому их шесть спрайтов остаются без замены. Если на актуальной иконке показана допустимая форма предмета с несколькими формами, делаем одну картинку с этой формой. Когда иконка показывает другой предмет, проверяем подтип и описание каталога. При явном противоречии сохраняем правильную форму и переносим совместимые цвета и детали с иконки.

Преобразуем рисунки в ракурс сверху с помощью ImageGen и агентов GPT‑6 Luna (max), используя карты референсов 5×5. Перерисовка по тексту не передаёт исходный дизайн, а вырезка готовой иконки оставляет её исходный ракурс. Спрайт сохраняет только предмет, без рамки и маркера иконки, фона и отделённых эффектов. Каждый файл остаётся уникальным RGBA PNG 512×512 с прозрачной рамкой от 32 пикселей. Пути, стабильные ID, игровые формы, параметры, правила и визуальные настройки размещения сохраняются.
