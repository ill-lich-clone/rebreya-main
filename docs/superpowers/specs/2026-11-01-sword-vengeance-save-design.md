# Меч мести: спасбросок

Владелец: `MagicItemsCompendiumService`, подключение через существующий combat hook. Исходник `magicItem.js`, id `меч-мести`: после настройки проклятый носитель, имея меч при себе, при каждом получении урона в бою выполняет спасбросок Мудрости Сл 15; провал описывает обязанность атаковать источник. Пользователь поручил автоматический спасбросок, а не изменение поведения игрока. Сохранить существующие авторские данные предметов и последствия оставить в описании результата.

Условия: настоящий урон больше нуля после расчёта dnd5e, начатый бой с участием конкретного Actor, предмет с точным catalog id находится в его инвентаре и настроен. Несколько экземпляров не должны создавать несколько бросков на одно событие. Нет броска при лечении, нулевом уроне, отсутствии меча, вне боя или при отсутствии настройки. Не выполнять дополнительных мутаций предметов и combat state. Встроенный hook вызывается только клиентом, непосредственно применившим урон, а не всеми клиентами. Повторная доставка одного события допускает дедупликацию только при надёжном ключе, не подавляющем реальные отдельные случаи урона.

Ограничение: в модуле нет отдельного достоверного состояния снятия проклятия или изгнания духа; текущая настройка — доступный сигнал. Не заявлять, что снятие проклятия и последствия провала автоматизированы.

Каталог исправляет ошибочную отметку `attunement: "0"` для точного id на обязательную; вновь созданные предметы получают dnd5e `system.attunement: required`. Существующие экземпляры автоматически не перенастраиваются: пользователь мог вручную снять проклятие или изменить предмет, а достоверной метки изгнания духа нет. Прежние экземпляры нужно настроить вручную, если они ещё прокляты. Отдельные применения урона считаются отдельными событиями: Foundry не предоставляет стабильный универсальный ID применения для безопасного межсобытийного объединения.
