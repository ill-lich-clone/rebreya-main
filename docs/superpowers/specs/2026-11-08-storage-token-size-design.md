# Размеры хранилищ при загрузке dnd5e 6

Одиночные предметы, кучи монет и постоянные хранилища сохраняют свои размеры при создании и перезагрузке мира. Пользователь выбрал точечную совместимость модуля. Используем штатные флаги dnd5e `lockSize` и `lockScale` только для классифицированных постоянных хранилищ и наземных куч на dnd5e 6+. Глобальная синхронизация размеров, обычные существа и хранилища на трупах сохраняют прежнее поведение.

Active GM при синхронизации фиксирует существующие токены до обновления их прототипов. Для незаблокированной наземной кучи при включённой синхронизации и известном размере актёра можно восстановить `width/height` из валидного `autoLayout`, если сохранённые размеры совпали с размером dnd5e, а `customFootprint` явно равен `false`. Блокировка и восстановление записываются вместе. Сохраняются позиция, глубина, поворот, масштаб текстуры, содержимое и настройки. Повторный запуск идемпотентен. Геометрия с ручной настройкой или недостаточными данными сохраняется.

Для четырёх ручных токенов мира локальная копия сцен от 2 ноября подтверждает `2×2` на тех же координатах. Отдельное восстановление использует точные UUID, ожидаемую текущую геометрию и штатный GM document API. Данные этого мира не входят в общую миграцию.
