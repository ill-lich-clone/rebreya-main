# Форма кружка вдохновения

Результат: переключатель остаётся штатным кругом 12×12 пикселей без вытягивания и сохраняет цвет пользователя, жёлтое свечение, существующие права и состояние. Причина: базовый стиль Foundry задаёт кнопкам min-height больше высоты кружка. Решение: переопределить min-height в существующем правиле кружка. Изменений игровых правил нет.
