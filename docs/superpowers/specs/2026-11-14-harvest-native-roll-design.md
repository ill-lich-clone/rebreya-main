# Штатное окно броска при разделке

Нажатие «Бросить» в окне разделки сразу открывает обычное окно проверки dnd5e на клиенте игрока. Чат показывает бросок и карточку результата с трофеями. Отмена броска позволяет снова открыть окно. Сервер связывает итог с сохранённой попыткой и выдаёт добычу один раз. Завершённый труп показывает «Уже разделан».
