# Top-down для магических предметов

**Результат.** Все 672 записи канонического `MAGIC_ITEMS` получают по одному отдельному спрайту для сцены. При размещении одного распознанного предмета используется его спрайт, аналогично обычным книгам и мебели. Иконка в листе, каталоге и инвентаре сохраняется.

**Внешний вид.** Камера строго сверху, предмет лежит на горизонтальной плоскости. Без подложки, текста, падающей тени и отделённых эффектов. Конечный файл — квадратный PNG 512×512 с реальным alpha и полностью прозрачной рамкой не менее 32 пикселей со всех сторон; контур не обрезан, без остатка фона и посторонних деталей. Стиль берём из `assets/top-down/items/gear/`. Сверяем форму с именем, подтипом и описанием записи: для явного длинного меча рисуем длинный меч. Для переменной формы выбираем один допустимый вариант для всей записи (например, длинный меч для «Оружия +1», кирасу для общего доспеха, стрелу для общего боеприпаса); это визуальное решение, игровой выбор не меняется.

**Подход.** Используем отдельные PNG из проверенных атласов, как в существующем производстве top-down. Рисовать каждую форму переменного оружия увеличило бы объём и противоречило запросу; брать существующие инвентарные иконки означало бы потерять ракурс и прозрачный контур. Генерацию выполняют агенты GPT‑6 Luna (max). Единый список связывает точный `magicItemId` с уникальным PNG. Индекс строится из оригинальных стабильных ID, включая ID, которые исторически отличаются от текущего имени.

**Контракты.** Канонический resolver получает identity из `flags.rebreya-main.sourceType = "magicItem"` и `magicItemId` самого Item, в том числе из подготовленного снимка контейнера. Если в старом снимке тип уже магический, но краткая identity ещё не содержит ID, проверяем канонические флаги сохранённой копии Item. У настроенного шаблона допускается ID выбранной основы, подтверждённый парой `magicEquipmentTemplate/magicEquipmentGearId`: спрайт по-прежнему определяется магическим ID. Имя, generic `magical`, неподдерживаемый ID и ID только строки не считаются совпадением. При отсутствии спрайта действует прежний fallback; смешанные кучи, валюты, обычное снаряжение, материалы, алхимия и существующие footprint остаются прежними. Не меняем механики, игровые параметры, документы предметов, источники их форм и не добавляем миграцию сцен. Доспехи сохраняют существующую категорию размера для одиночного предмета на сцене.
