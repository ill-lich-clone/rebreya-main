# SmallTime: сохранение закрепления при щелчке

Статус: согласовано пользователем 2026-10-25; самостоятельное составление плана и выполнение разрешены. Владелец runtime — установленный sibling-модуль `smalltime`, класс `SmallTimeApp` в `scripts/smalltime-app.mjs`.

## Наблюдаемый результат

Щелчок по полоске перетаскивания закреплённых часов без движения оставляет часы закреплёнными, включая после перезагрузки. Открытая или закрытая строка даты результата не меняет.

## Подтверждённая причина

`onDragEnd(event)` сохраняет `pinned=false` и прежнюю свободную позицию даже при отсутствии `onDragMove`. При этом DOM остаётся `.pinned`; следующая загрузка использует старые свободные координаты. Сценарий воспроизведён исполнением настоящего класса в Node VM для высот 58px и 79px.

## Подход

Исправить существующий `SmallTimeApp.onDragEnd(event)`: после освобождения pointer capture и удаления listeners завершать жест без записи settings, если он начался закреплённым и `hasUnpinnedOnThisDrag` остался false. Очистить animation и `_dragState` перед возвратом. Эти же правила действуют для `pointercancel` без движения.

Альтернатива — wrapper в compatibility adapter Rebreya — добавляет второго владельца поведения стороннего модуля. Рекомендуется прямое минимальное исправление SmallTime с versioned patch record в Rebreya.

## Сохраняемые контракты и границы

- Реальное перетаскивание, порог начала движения, pin zone и повторное закрепление работают по прежним правилам.
- Свободное окно сохраняет прежнее поведение и выбранные пользователем координаты.
- Keys/scopes/defaults settings, календарь, дата, world time, права GM/player и игровые документы не меняются.
- Единственное намеренное изменение — завершение неподвижного жеста закреплённого окна больше не записывает `position`/`pinned`.
- Ранее сохранённое `pinned=false` автоматически не сбрасывается: оно неотличимо от намеренного свободного расположения. Для уже смещённых часов остаётся штатный Shift+клик по подписи `Player Visibility Default` в настройках SmallTime.

## Поставка и проверка

- SmallTime 2.0.4 → 2.0.5; новый versioned entrypoint загружает изменённый source с новым cache key. Rebreya runtime и его версия 1.5.5 не меняются, поскольку в нём меняются только тесты и документация patch record.
- До runtime edits: failing regression для щелчка закреплённых часов с закрытой/открытой датой и pointercancel; preservation tests для drag-out, drag-back, свободного окна и чужого pointer ID.
- Тесты исполняют настоящий установленный класс. Проверяются settings, DOM parent/classes, координаты и cleanup; Foundry/DOM I/O заменяется минимальными doubles.
- Сохранить точные before/after hashes, backup и обратимый patch в `tools/local-module-patches/2026-10-25-smalltime-pinned-click/`; обновить профильный раздел паспорта функций.
- Проверить focused suite, полный Node suite Rebreya, JS/MJS syntax, JSON, forward/reverse patch и `git diff --check`; commit/push только task files в `lich_branch`.
