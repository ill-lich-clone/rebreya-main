# Запрос проверки разделки и результат в чате

После выбора навыка и крови игрок отправляет штатный запрос dnd5e в чат. Проверка проходит с обычным диалогом броска за выбранного персонажа. Отмена оставляет запрос доступным. Система принимает связанный с запросом бросок этого персонажа и один раз выдаёт трофеи по действующим правилам. Результат получает игрок и Мастер. Карточка показывает персонажа, существо, проверку, Сл, степень успеха и полученные трофеи. При тяжёлом провале карточка напоминает про урон.

Когда попытка завершена, в корневом окне добычи показывается неактивная кнопка «Уже разделан». Незавершённую выдачу можно продолжить. Ручное восстановление Мастером остаётся доступным.
