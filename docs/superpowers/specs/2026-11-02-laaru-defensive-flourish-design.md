# Росчерки Коллегии Мечей Laaru

После попадания оружием в рамках действия Атака в свой ход, не чаще одного раза за ход, владелец может выбрать росчерк. Оборонительный расходует одну кость имеющегося вдохновения Laaru, добавляет её к урону атаки и к КД до начала следующего своего хода. При Мастерском росчерке доступна альтернатива d6 без расхода. Отказ и промах не расходуют ресурс. Сохраняются авторская формула и штатные состояния, идемпотентность, права, крит и порядок расчёта Midi. Скорость при действии Атака сохраняется по ранее согласованной спецификации.

Режущий и мобильный по новому указанию пользователя: выдать только бросок кости и расход ресурса; урон, выбор второй цели, отталкивание и реакционное перемещение игрок разрешает вручную. Других изменений игровых правил нет. Точная ability/source UUID Laaru, существующий BardicInspirationCompatService и подтверждённый Midi workflow; при неоднозначном/неподдержанном состоянии не выполнять сомнительные изменения, объяснить ручное действие. Никакого управления пользовательским интерфейсом Foundry без отдельного разрешения.

Midi не всегда сохраняет факт попадания в карточке: источник записывает подтверждение из текущего workflow в module flag; GM проверяет автора, токены и цель. Оборонительный росчерк при попадании одной атакой по нескольким целям и крит с нестандартной сложной формулой требует ручного разрешения, без расхода: Midi заранее показывает общую сумму реакциям. Для ручных вариантов GM публикует сохранённый бросок с постоянным идентификатором сообщения; при потере подтверждения возможен безопасный повтор и восстановление без нового расхода или второй карточки.
