# Запись календаря на границе раунда

При ходе, который переводит игру на следующий раунд, SmallTime сохраняет текущее время группы. Rebreya обновляет только поля часов выбранной группы в прежней настройке `groupState`, без глубокого копирования реестра и нормализации других доменов. Foundry сериализует настройку штатным способом, по-прежнему уведомляя клиентов и подписчиков.

Запись читает актуальные данные внутри существующей очереди `setting:groupState`, переиспользует проверку полномочий активного GM и сохраняет отдельными объектами только корень, индекс, выбранную группу и её календарь. Журнал и пользовательские поля календаря, другие группы и параллельные доменные записи сохраняются. Урезанная запись применяется к патчу часов, многостадийные переходы даты и `updateWorldTime` идут по прежним путям.

Отдельная настройка только для часов убрала бы сериализацию реестра, но потребовала бы менять хранение, читателей и события синхронизации. Для текущего профиля устраняем два прохода Rebreya по реестру, сохраняя прежнее хранилище.

Приёмка включает регрессии на обход вложенных архивов, конкурентные записи, сбой сохранения и существующие тесты календаря, времени и эффектов. После загрузки Rebreya Main 1.5.89 проверяем исходные 16 токенов Мицелии в том же порядке за десять раундов. Окно остаётся в фоне. Диагностические выключатели сохраняют текущие значения.
