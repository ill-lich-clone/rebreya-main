# Макрос создания объектов на карте

## Цель

Добавить управляемый модулем GM-макрос `Создать объект на карте`. Макрос создаёт на активной сцене прозрачный токен с именем и базовыми характеристиками объекта, не закрывая изображение карты и не создавая отдельного Actor для каждого объекта.

## Пользовательский путь

1. Мастер запускает макрос из каталога макросов или панели быстрого доступа.
2. Открывается компактная форма с полями: имя, максимальные хиты, КД, порог урона и размер в клетках.
3. После подтверждения модуль переходит в режим размещения.
4. Следующий ЛКМ по активной сцене создаёт объект в выбранной клетке.
5. `Esc` или ПКМ отменяют размещение без создания документов.

## Представление объекта

- Модуль поддерживает один NPC Actor-шаблон `Rebreya: Объект карты`, скрытый от игроков через `ownership.default = NONE`.
- Каждый создаваемый токен не связан с Actor (`actorLink: false`) и получает собственный ActorDelta.
- В ActorDelta записываются имя, текущие и максимальные хиты, КД с расчётом `flat` и порог урона.
- Токен использует прозрачную текстуру из ресурсов модуля, нейтральную диспозицию и отключённое зрение.
- Имя и полоса хитов отображаются постоянно. Прозрачная область токена остаётся выбираемой в пределах заданного размера.
- На Actor-шаблоне, макросе и токенах сохраняются стабильные флаги `rebreya-main`, позволяющие обновлять управляемые документы без дубликатов.

## Архитектура

Новый `MapObjectTokenService` отвечает за четыре независимые операции:

1. Синхронизация системного Actor-шаблона на active GM.
2. Синхронизация world-макроса на active GM.
3. Нормализация и проверка введённых характеристик.
4. Построение TokenData и создание токена на активной сцене.

Публичный метод `game.rebreyaMain.createMapObjectToken()` открывает форму, ожидает точку размещения и делегирует создание сервису. Сам код world-макроса остаётся коротким и вызывает только этот публичный метод.

## Значения и ограничения

- Имя обязательно, значение по умолчанию: `Объект`.
- Хиты: целое число от 1 до 1 000 000, по умолчанию 10.
- КД: целое число от 0 до 100, по умолчанию 10.
- Порог урона: целое число от 0 до 1 000 000, по умолчанию 0.
- Размер: число от 0,25 до 20 клеток с шагом 0,25, по умолчанию 1.
- Координаты привязываются к сетке, а токен центрируется на выбранной точке.

Некорректные значения не создают токен и показывают уведомление. Макрос доступен только мастеру. Отсутствие активной сцены или canvas завершает операцию с понятным предупреждением.

## Синхронизация

При `ready` active GM ищет Actor и Macro по стабильным флагам. Отсутствующие документы создаются, существующие обновляются только при изменении управляемых данных. Пользовательские документы без этих флагов не затрагиваются.

## Проверка

- Unit-тесты нормализации формы и построения Actor/TokenData.
- Тесты идемпотентной синхронизации Actor и Macro.
- Тесты размещения, привязки к сетке и отмены.
- Тест запрета запуска не-GM пользователем.
- Полный набор тестов модуля и живая проверка в Foundry VTT 13.
