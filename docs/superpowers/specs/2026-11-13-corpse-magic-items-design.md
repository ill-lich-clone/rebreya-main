# Магические предметы в добыче с трупа

Игрок видит и получает «Кинжал верного удара» с его свойствами и активностями, когда этот предмет находится у NPC. Источник предмета для обычного снаряжения, количество и правило сломанного доспеха сохраняются. Магические оружие, экипировка, расходники, инструменты и предметы добычи берутся из данных самого NPC. Предмет отделяется от экипировки, контейнера и настройки владельца. Требование настройки сохраняется.

Исправление применяется при создании добычи и при открытии старого трупа. Сохранённая строка меняется, если она содержит обычный каталоговый предмет, исходный ID однозначно указывает на магический предмет того же NPC и строка ещё доступна. При исправлении сохраняются ID строки, остаток количества и записи выдачи. Добытые трофеи разделки и остальное содержимое продолжают храниться в том же хранилище.
