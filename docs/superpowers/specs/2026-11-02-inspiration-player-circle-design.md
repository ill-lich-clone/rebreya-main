# Переключатель вдохновения на кружке игрока

Результат: штатный цветной кружок активного пользователя становится кнопкой; активное вдохновение отмечается жёлтым свечением. Отдельная звезда отсутствует. Мастер управляет всеми, игрок — своим назначенным персонажем. Для мастера без персонажа состояние сохраняется в его User flag; при наличии персонажа используется штатное Actor.system.attributes.inspiration. Другие пользователи без персонажа не получают работающей кнопки. Права, обновление при изменении состояния и точечный рендер сохраняются. Без управления desktop и без изменения данных мира при проверке.

Решение: вместо отдельного значка заменить CSS-псевдоэлемент кнопкой того же размера и цвета; прежний подход с отдельной иконкой не соответствует запросу.
