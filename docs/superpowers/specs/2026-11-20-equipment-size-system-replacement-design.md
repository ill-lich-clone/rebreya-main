# Полная замена system при обновлении предмета

При входе активного ГМа синхронизация магических предметов должна завершать обновление «Ожерелья огненных шаров» без `DataCloneError`. Foundry 14 преобразует `==system` в `ForcedReplacement` до вызова `preUpdateItem`. Хук размера экипировки должен передавать полную замену `system` без преобразований. Это сохраняет нативную семантику замены, тип предмета, новые системные данные и остальные поля того же обновления.

Обычные вложенные и точечные правки продолжают использовать текущие правила размера, урона, веса и цены. Маршрут миграции и форма записываемых им данных сохраняются.
