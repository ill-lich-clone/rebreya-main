# Круговая атака оружием

Дата: 2026-10-24. Статус: согласована пользователем; реализована в версии 1.5.1 (границы live QA см. в отчёте проверки).

## Наблюдаемый результат

У оружия со свойством `lchWhirl` появляется дополнительная активность «Круговая атака». Обычные активности оружия сохраняются. Игрок запускает её из того же предмета.

Активность автоматически собирает всех существ в фактической досягаемости этого оружия на сцене, включая союзников и нейтральных существ, кроме самого атакующего. Ручной выбор целей не ограничивает этот набор. Используется существующее правило досягаемости модуля, включая размер, природные бонусы и бонус оружия, без отдельного фиксированного радиуса.

Выполняется один бросок атаки; его результат сравнивается с КД каждого существа. По каждой поражённой цели наносится половина обычного урона оружия с сохранением штатной обработки типов урона, сопротивлений, иммунитетов и критического попадания. Округление половины — штатное округление урона вниз, без преждевременного изменения исходной формулы.

Дополнительные эффекты, в том числе «Скрытая атака», разрешаются только для одной выбранной поражённой цели. Дополнительный урон «Скрытой атаки» также делится пополам и не распространяется на остальных. Условия доступности самих способностей и их собственные ограничения сохраняются.

**Уточнение пользователя:** ограничение круговой атаки «один раз в ход» не автоматизируется. Не вводятся счётчик, блокировка, флаг использования или сброс по ходу. Соблюдение этого правила остаётся за игроками.

## Подход

Выбранное пользователем представление — дополнительная активность внутри предмета. Она использует существующие владельцы атак и расчёта досягаемости, а не отдельный макрос или отдельное окно атаки.

Рассмотренные альтернативы: переключатель в обычной атаке уменьшает число активностей, но скрывает отдельный способ применения; отдельный макрос требует запуска вне предмета и дублирует интеграцию. Дополнительная активность прямо соответствует запросу и сохраняет привычную обычную атаку.

## Владельцы и сохраняемые контракты

- Свойство оружия: существующий `lchWhirl`; не добавлять второе свойство.
- Проекция и синхронизация активности: существующие пути подготовки/обновления предметов; охватить уже существующее оружие, а не только новые импорты. Не перезаписывать авторские активности и формулы.
- Runtime атаки и досягаемость: `scripts/combat/attack-service.js`; использовать канонический расчёт, при необходимости выделив общий метод без изменения его результата.
- «Скрытая атака»: `scripts/combat/rogue-automation-service.js`; выбранная цель должна ограничивать и дополнительный урон, и соответствующий дополнительный эффект.
- Composition: `scripts/main.js`, без второго независимого владельца тех же hooks.
- Не менять настройки, формулы, расходы ресурсов, правила количества и обычные атаки вне заявленного поведения. Круговая атака заменяет одну атаку оружием, а не создаёт отдельное полное действие поверх неё.
- Не добавлять отдельное правило видимости, враждебности или исключения союзников. Геометрию и препятствия обрабатывать по действующим правилам рукопашной досягаемости проекта.

## Проверка

До runtime-правок закрепить focused-регрессии: наличие активности по свойству; сохранение обычных и авторских активностей; обновление существующих предметов без дубликатов; все фракции в пределах канонической досягаемости; исключение атакующего и существ вне досягаемости; один бросок с разной КД целей; половина обычного урона; половина «Скрытой атаки» только выбранной поражённой цели; отсутствие автоматического лимита круговой атаки; сохранение обычной атаки.

Проверить интеграцию на установленной dnd5e 5.2.5 и Foundry 13 в доступном live world. Если live-проверка недоступна, отдельно указать непроверенные сценарии, не объявляя их подтверждёнными.

При реализации обновить паспорт функций и профильную пользовательскую документацию, повысить версию модуля и синхронизировать versioned entrypoint. Перед commit выполнить полные проверки runtime по AGENTS.md; commit и push — только в `lich_branch`.
