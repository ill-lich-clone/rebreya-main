# Native NEXT diagnostic

Use a code switch for a temporary comparison. The deployed build keeps Rebreya's grouped turn engine and its turn-time aim sweep off, including for existing combats with saved group flags. Foundry owns navigation, position, normal turn events and provider effects. Rebreya's independent reaction refresh and ordinary effect subscribers receive those events. The grouped camera/title and grouped-specific phases are paused.

The start macro keeps existing GM authorization and token eligibility, creates missing combatants, rolls native initiative and starts Foundry normally. Do not migrate or delete saved group journals and do not accept grouped transition or recovery commands during the comparison. Perform the comparison in a new test encounter: advancing a formerly grouped encounter in Foundry moves its native position while the saved group journal stays at its last grouped position.

Skip aim cleanup on ordinary NEXT. Manual aiming, cancellation by movement and cleanup at combat deletion stay available. An immobile actor's temporary aim movement effect can survive a turn boundary while the comparison is active. This comparison is intended for an encounter without active aim.
