# Совместимость лутгена с Foundry 14

В Foundry 14 обычная и подготовленная генерация, отправка результата в чат и выдача должны работать через `foundry.utils.randomID()`. Формулы, количество, фильтры, бюджет, траты и контракты подготовленной выдачи сохраняются.

Владелец legacy-заявки из `createItem` при отсутствии доверенного исходного сообщения возвращает `false` и снимает с созданного предмета временную метку. Активные доверенные сообщения используют прежнюю выдачу; ручная заявка по отсутствующему сообщению и реальные ошибки записи сохраняют текущую обработку. Ветка player socket поддерживает то же поведение. Метка при явном получении предмета себе уже не нужна: выдача списывает строку отдельным вызовом.

На dnd5e 6+ активный ГМ при запуске заменяет четыре удалённых пути иконок DFreds `exhaustion2.svg`–`exhaustion5.svg` на существующие dnd5e-иконки того же уровня. Миграция ограничена активным контейнером эффектов DFreds среди мировых Items и записывает только `img` точных совпадений. Резервные копии, прочие картинки, эффекты и настройки сохраняются. Повторный запуск не пишет документы.

Обновление установленного Dice Tray выполняется отдельно. Ошибки подготовки предметов в приложенном логе совпадают со срывом загрузки двух скриптов регистрации. Сетевой сбой после сна исключён из изменений.
