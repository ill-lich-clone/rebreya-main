# Разделение инструкций агента и паспорта функций

## Цель

Сократить автоматически загружаемый контекст, не потеряв обязательные правила работы и точную карту реализации проекта.

## Структура

### `AGENTS.md`

Короткий корневой документ, который содержит только постоянно нужный контекст:

- обязательный Git-процесс и работу только в `lich_branch`;
- быстрый вход и архитектурные слои;
- порядок перехода к реализации;
- минимальные проверки перед завершением;
- правило актуализации документации;
- ссылку и условие перехода к паспорту функций.

Обязательное правило маршрутизации: если для задачи нужны конкретные функции, методы, владельцы данных, маршруты вызовов, точки расширения или профильные тесты, агент должен открыть `docs/function-passport.md` и читать только относящийся к задаче раздел.

### `docs/function-passport.md`

Подробный документ, загружаемый по требованию. В него переходят:

- контракт актуальности паспорта;
- паспорта функций и подсистем;
- публичные методы и внутренние entrypoints;
- владельцы данных и последовательности вызовов;
- ограничения, точки реализации и профильные тесты;
- диагностическая карта выбора владельца изменения.

Паспорт описывает текущее состояние, а не ведёт хронологический журнал.

## Правило сопровождения

Изменения и новые методы должны отражаться в `docs/function-passport.md` в том же commit, если меняются контракт, владелец, data flow, публичный API, socket-команда, hook, refresh scope или основная точка тестирования. Корневой `AGENTS.md` обновляется только при изменении общих правил работы или маршрутизации.

## Миграция

Текущий `AGENT.md` удаляется после переноса содержимого. Все его внутренние ссылки заменяются на `AGENTS.md` или `docs/function-passport.md` по смыслу. Дублирование полного паспорта в корневом файле не допускается.

## Проверка

- `AGENTS.md` остаётся самодостаточным для начала работы и выбора слоя.
- По явному правилу из `AGENTS.md` можно однозначно найти паспорт.
- Паспорт сохраняет все двадцать существующих разделов подсистем.
- Поиск не находит устаревших инструкций обновлять `AGENT.md`.
- Markdown и Git diff не содержат повреждённой кириллицы или пробельных ошибок.
