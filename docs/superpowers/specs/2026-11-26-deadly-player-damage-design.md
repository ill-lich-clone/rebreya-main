# «Смертельное» при атаке игрока

Когда MIDI-QOL применяет урон по попаданию оружием игрока через GM, «Смертельное» обнуляет оставшиеся HP чужого токена, если обычный урон уменьшил HP, а остаток положительный и не выше порога. Манекен с порогом 50000 должен упасть без ошибки ActorDelta. Сообщение появляется после успешной записи.

Обработка использует существующий GM-сокет MIDI-QOL и его хуки вокруг записи урона. Источник восстанавливается из карточки атаки. Карточка должна ссылаться на оружейную атаку указанного источника и принадлежать пользователю с правом на источник. Для цели, которую автор карточки может обновлять сам, остаётся прежний путь. На чужой цели RollComplete прекращается до записи.

Формула порога, настройки MIDI-QOL, локальный путь для владельца/GM и существующий обработчик явного UUID оружия сохраняются. Урон, который ещё не применён, и урон только по временным HP не запускают новую обработку. Новых socket-команд нет.
