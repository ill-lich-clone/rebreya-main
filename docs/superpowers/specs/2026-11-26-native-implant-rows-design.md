# Штатное открытие имплантов

Сохраняем установленный и доступный наборы, их порядок, счётчик, правила отбора и импланты из контейнеров. В каждой строке отображается название с обычными элементами управления dnd5e. Нажатие на название открывает Item внутри Foundry через штатное действие view. Обе секции используют стандартный компонент инвентаря и одну колонку управления без заголовка.

Штатный шаблон и компонент переиспользуют обработчики открытия, меню и описания, включая разрешение документов из коллекции Actor. Вариант с собственным обработчиком открытия дублировал бы эту работу. Ссылки с href и навигация для имплантов не нужны.
