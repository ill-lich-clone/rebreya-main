# Отображение папок и сводка по папке инвентаря

## Поведение в Foundry

- Кнопка «Скрыть папки» рядом с поиском и сортировкой переключает окно на единый список корневых и вложенных предметов, включая содержимое свёрнутых папок. В списке действуют текущие поиск по предметам, фильтр по типу и сортировка всего результата. В отдельном окне папки список ограничен её веткой.
- «Показать папки» возвращает дерево с прежним раскрытием. Режим действует в текущем окне до его закрытия и скрывает строки папок и панель закреплений. Кнопка создания папки доступна в режиме дерева. При переключении используются данные уже открытого окна. Дерево, закрепления, содержимое папок и правила переноса сохраняются.
- Кнопка ⓘ «Информация о папке» на строке папки доступна всем, кто видит папку. Диалог показывает вес, оценку по цене 100% и оценку по цене 50% для самой папки и всех её подпапок. Содержимое учитывается независимо от поиска, фильтра и раскрытия. Пустая папка показывает нули.
- Вес суммируется по предметам с учётом количества, дробных материалов и единиц веса. Это вес самих предметов по членству в папках склада, включая вещи из безразмерных сумок. Общие монеты группы и монеты в контейнерах в эту сумму не входят.
- 100% совпадает с оценкой по ценам позиций инвентаря, включая магические вещи с указанной ценой. 50% равны половине полной оценки с округлением вниз до целой медной монеты. Действия продажи и разбора сохраняют свои проверки, расчёты и права доступа.

## Реализация

Плоский режим расширяет существующую проекцию `projectInventoryFolderRows` и получает тот же компаратор, что и дерево. Кнопки переключения и просмотра сводки принадлежат `InventoryApp`. Сводку считаем по нужной ветке кешированного дерева при открытии диалога. Для цены переиспользуем общий расчёт стоимости позиций. Настройки, Actor/User flags, команды сокетов и создание дополнительных приложений для этой задачи не нужны.

Скрытие папок средствами CSS сохранило бы зависимость видимых предметов от раскрытия и порядка веток. Общие итоги в каждой строке добавили бы расчёт при любом рендере. Плоская проекция и сводка по нажатию поддерживают нужное поведение через существующий контекст окна.

## Проверка

Регрессионные тесты проверяют вложенность и область просмотра, поиск, тип и глобальную сортировку, возврат к сохранённому раскрытию без записей и повторного запроса снимка. Сводка проверяется через кнопку для обычного пользователя на вложенных и скрытых фильтром предметах, дробных количествах, разных единицах веса, цене обеих ставок и пустой папке. Существующие тесты продажи, веса склада и переноса проверяют совместимость.
