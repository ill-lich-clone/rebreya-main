# Сохранение ручного размера наземных токенов

## Наблюдаемый результат

Пользователь вручную меняет ширину/высоту либо масштаб изображения токена Rebreya. После открытия, добавления/изъятия содержимого, объединения добычи, обновления изображения и startup-ремонта существующий токен сохраняет эти значения. Например, монетная куча 2×2 не возвращается к 0.5×0.5 после получения части монет или смены состава номиналов. Ручные разные scaleX/scaleY также сохраняются. При сохранении ручного footprint координаты x/y не меняются.

Токены без ручных изменений продолжают автоматически менять размеры при переходе одиночного предмета в категорийную кучу и обратно. Новые токены получают прежний размер и масштаб, включая прямоугольную мебель с cardinal rotation. Обычные персонажи/NPC и токены, которые модуль не обновляет, не затрагиваются.

## Причина и владелец

`StorageGroundPileService.#writePile()` в `scripts/data/storage-ground-pile-service.js` безусловно перезаписывает width/height, texture.scaleX/scaleY и координаты вокруг центра. Этот метод используется refresh, merge и legacy repair. Создание токена в `#transferPreparedSnapshotNow()` уже вычисляет исходный автоматический layout. Изменение выполняется в этом существующем владельце; второго владельца или дополнительного hook не нужно.

## Подход

В существующем groundPile flag хранить последний автоматический layout и независимые признаки ручного footprint/масштаба. Перед записью сравнить текущие значения токена с последними автоматически установленными. Отличие переводит соответствующую группу в ручной режим; все последующие refresh сохраняют актуальные значения токена, в том числе после перезагрузки и дальнейшего ручного редактирования. Ручной footprint и ручной масштаб независимы. Для старых токенов без записи layout использовать автоматический layout предыдущей presentation как исходную точку сравнения; нестандартные размеры сохранять. Некорректные/отсутствующие значения не считать допустимым ручным размером.

При автоматическом footprint сохраняется прежний пересчёт вокруг центра. При ручном footprint не переписывать width/height/x/y. При ручном масштабе не переписывать scaleX/scaleY. Имя, art, содержимое, денежные балансы, permissions, нейтральность/отключённое зрение и существующая политика rotation продолжают обновляться прежним способом. Изменение размера ровно на уже установленное значение неотличимо от отсутствия изменения и не требует отдельного режима.

## Контракты и deliberate changes

Единственное изменение поведения — обновления существующей кучи перестают сбрасывать её ручные размеры/масштаб. GroundPile flag получает обратно совместимую необязательную metadata layout; старые flags остаются читаемыми. Нет новой настройки, socket command, UI или privileged mutation route. Количества, authored formulas, spending/budget, receipts/recovery и правила настоящих контейнеров сохраняются. Пересоздание нового токена из предмета продолжает применять прежние defaults; сохранение layout переносимого предмета не входит в эту правку.
