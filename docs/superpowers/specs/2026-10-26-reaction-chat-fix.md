# Исправление карточки и завершения реакции

Продолжение согласованной спецификации `2026-10-23-global-reaction-chat-design.md`. Пользователь 2026-10-26 поручил продолжить исправление и закоммитить его; шесть уже изменённых планов других задач не трогать.

## Наблюдаемый результат

- Общий чат показывает компактную карточку Rebreya: тёмная поверхность, золотой акцент, иконка и подпись «Реакция». Основной текст остаётся ровно «Имя выбирает реакцию».
- После успешной оплаты, применения и списания реакции удаляется именно её карточка. Кандидат, содержащий только Actor UUID из capability index, работает так же, как кандидат с готовым Actor Document.
- При отказе, закрытии, таймауте, неуспешной оплате/применении карточка остаётся с текстом «Имя не применил реакцию» и приглушённым оформлением. Одного клика недостаточно для удаления.
- Имена экранируются, длинный текст переносится в узком чате. Оформление ограничено собственным CSS-классом и читаемо в светлой/тёмной теме Foundry.

## Причина и владельцы

`ReactionQueueService._executeAccepted()` использует только внедрённый `actorResolver`, хотя composition root его не передаёт. UUID-only кандидаты Rune Knight и spell provider получают `null` при финальном списании. Существующие методы создания карточки и проверки резерва уже используют `globalThis.fromUuid` как runtime fallback. Исправление выравнивает этот путь, сохраняя канонический ledger и rollback.

Оформлением владеют `_beginReactionMessage` / `_finishReactionMessage` и scoped CSS в `styles/main.css`. Native MIDI остаётся в существующем адаптере; диагностическая проверка настоящего player client обязательна.

## Сохраняемые контракты и намеренные изменения

Все игроки/NPC, native MIDI activity и optional AC, 10 секунд выбора, applying-резервы, ownership/transport authorization, формулы, бюджеты, quantity rules, бесплатные реакции и несколько использований сохраняются. Нет новых настроек, очередей, протоколов или изменений зависимости MIDI. Намеренные изменения: оформленная карточка и правильное завершение UUID-only кандидатов вместо ложного отказа.

Версия выпуска, forwarder, изменённый runtime import и CSS cache key — `1.5.7`. Старые forwarders и cache keys неизменённых подсистем сохраняются.

## Проверка

Сохранить остальные lifecycle/managed/MIDI проверки, приблизить native dialog harness к фактическому `button.callback`. В живом Foundry проверить player→GM и NPC, подтверждённый успех, отмену, таймаут и оформление.
