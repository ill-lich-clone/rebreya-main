# Совместимость усовершенствований и ответный урон шипов

Шесть каталожных условий проверяют фактическую цель установки. Золотая инкрустация требует фокусировку, кожаная обмотка — смену хвата, лужение — металл, льняная тетива — лук или арбалет, свинцовая подкладка — закрывающуюся чудесную ёмкость, якорь реальности — носимый чудесный предмет. Подходящая цель по-прежнему требует свободный слот, одного владельца и отдельный экземпляр. Метаданные без доказательства конкретного признака не дают разрешение. Каталожные формулы, эффекты этих шести позиций и пользовательские профили сохраняются.

При завершении рукопашной атаки по носителю экипированной «Шипастой отделки доспеха» атакующий получает 2 колющего урона и при попадании, и при промахе. Дальнобойная и брошенная атаки не срабатывают. Повтор события по той же цели не добавляет урон. Урон проходит через dnd5e с обычными иммунитетами, сопротивлениями и временными HP. Эффект применяется за один удар со стороны каждого атакованного носителя, даже если на нём несколько экземпляров отделки.

Боевое событие берётся из завершённого MIDI workflow либо карточки нативной атаки при выключенном MIDI. GM проверяет владельца атакующего, активность и цель по карточке, ищет фактически экипированный предмет и связанное каталожное улучшение. Сокет принимает только ссылки на карточку и токен. Квитанция записывается одновременно с уроном на Actor атакующего.
