# Компактное снаряжение магазина

Согласовано в чате: финальный макет с текстурой, цифрами непосредственно на магазине, коротким списком боеприпасов, строкой схемы и иконками разрядки/повторной зарядки. Пользователь поручил сохранить ассеты в модуле и продолжить реализацию.

## Наблюдаемый результат

Одно компактное окно около 620×420 вместо 960×760. Одна шапка с оружием и количеством; крестик закрывает без применения. Цифры/значки на существующей визуализации выбирают группу атаки. Клик по боеприпасу заменяет выбранную группу в черновике, drag-and-drop сохраняется. Выбор остаётся на редактируемой группе. Тип, количество и перестановка выбранной группы доступны; неполные группы помечаются постоянно. Совместимые боеприпасы — плотные строки с иконкой и свободным количеством; эффект выбранного типа показывается один раз, ручные эффекты не теряются. Заполнение остатка остаётся отдельным действием.

Низ: `Схема: [Без схемы ▾] [Сохранить…]`, затем две подписанные через tooltip/aria-label иконки разрядки и зарядки как в прошлый раз, основная кнопка подтверждения. Сохранение раскрывает имя/действия управления без постоянной громоздкой формы. Существующие схемы можно применить, обновить, сохранить копией, переименовать и удалить; изменённая схема отмечена. Последняя схема доступна также из списка как предварительный просмотр. Иконка повтора сохраняет прежнюю семантику немедленного commit последнего состава. Разрядка очищает черновик, подтверждение явно называется «Подтвердить разрядку».

## Сохраняемые контракты

Владелец UI — AmmunitionMagazineApp/MagazineDraft; владелец записи — CombatAttackService.commitMagazine. Schema, flags, API, OWNER/GM-права, revision, inventory/reservoir, refund, legacy resolution, группы 1/3/6, однородность, хвост вместимости, authored damage/effects и бюджет патронов не меняются. Сохранение схем остаётся частью черновика до commit. Крестик/Esc не пишет Documents. Все семейства визуализаций сохраняются: curved, tube, chambers, muzzle, cells. Новые sockets/hooks/settings не нужны.

## Подходы и ограничения

Первоначальные крупные карточки отклонены пользователем. Выбран compact direct manipulation с цифрами на магазине вместо отдельного списка атак. Скрытие всех схем в меню отклонено: выбор и сохранение видимы. Новый растровый фон генерируется отдельно; существующие магазин и патроны переиспользуются, иконки действий — маленькие SVG. Оригинальные иллюстрации не перезаписываются. CSS ограничен окном. Большие ёмкости/длинные имена допускают локальную прокрутку; клавиатурные названия и фокус обязательны.

Намеренные изменения поведения: клик строки вместо кнопки «В ячейку»; отсутствие автоперехода к следующей группе; компактное раскрываемое управление схемами; удаление дублирующей отмены. Механика игры не упрощается.

## Проверка

Focused tests UI/draft и существующие combat tests; regression на shortage, partial tail, legacy, preset identity и отсутствие writes до подтверждения. Полная Node suite, JS syntax, JSON parse, diff. Native Foundry QA разрешена пользователем отдельно: только локальные disposable данные, без изменения игровых Actor. Версия 1.5.65, forwarder и cache import согласованы; commit/push только lich_branch.
