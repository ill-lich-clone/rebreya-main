# Загрузка шаблона хранилища

При открытии хранилища Foundry должен получить существующий шаблон `modules/rebreya-main/templates/storage-app.hbs` и отрисовать окно. В версии 1.5.66 сервер получает путь с `?v=1.5.48` и определяет его расширение как `.48`, поэтому отклоняет запрос до чтения файла.

Пользователь выбрал правку по образцу инвентаря. `StorageApp.PARTS.main.template` передаёт чистый путь к файлу. Обновление клиентского кэша выполняется через новую версию manifest, forwarder и cache key импорта `StorageApp` в composition root. Настройки, данные, права доступа, правила открытия и переноса, API и содержимое шаблона сохраняются.

Регрессионный тест проверяет фактическое значение `StorageApp.PARTS.main.template`, допустимое расширение и наличие файла. Поиск по runtime проверяет другие пути к шаблонам с query или fragment.
