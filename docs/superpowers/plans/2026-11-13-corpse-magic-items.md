# Исправление магических предметов в добыче

Спецификация находится в `docs/superpowers/specs/2026-11-13-corpse-magic-items-design.md`.

1. Воспроизвести подмену в `tests/corpse-storage-materializer.test.mjs`. Проверить существующую строку в `tests/storage-service.test.mjs`, включая остаток, уже выданный предмет и трофеи разделки.
2. В `CorpseStorageMaterializer` распознавать магию до выбора обычного предмета. Сохранять экземпляр и использовать ту же сборку для исправления по ID исходного предмета.
3. Подключить исправление к `StorageService.open()` для уже материализованных мёртвых NPC. Обновить паспорт, версию модуля и ключи кэша. Прогнать профильные и полные проверки, затем опубликовать в `lich_branch`.
