# Независимые слоты куклы героя

[Спецификация](../specs/2026-11-19-hero-doll-independent-hands.md)

1. В `hero-doll-instances`, `hero-doll-owner-route` и `hero-doll-presets` проверить доступность обычного меча до и после смены хвата, сохранённые слоты, фокус при занятых руках, неизменность хвата при работе с куклой и совместимость старых пресетов. Зафиксировать падения на текущем коде.
2. В `HeroDollService` использовать один источник слотов. Формировать список кандидатов по совместимым слотам. Направить слоты рук по общему OWNER/GM пути экипировки. Убрать запись хвата из назначения, снятия и применения пресета. Сохранить проверки существования, совместимости, количества, компенсацию и cleanup нового остатка.
3. Запустить профильные проверки куклы, удержания и заклинаний с предметов. Обновить паспорта, выпустить `1.5.100`, проверить полный набор тестов и diff, затем выполнить commit и push в `lich_branch`.
