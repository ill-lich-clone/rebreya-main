# План обновления магических спрайтов по иконкам

1. Зафиксировать ID из сверки с набором иконок Foundry. В сверке отмечены 138 похожих спрайтов, 469 с заметными отличиями оформления и 65 с отличием формы. Сверить референсы с сохранённым компендиумом. Исключить шесть записей, для которых он использует старые именные изображения. Сохранить исходные SHA-256, чтобы подтвердить замену ровно 528 файлов и сохранность остальных 144.
2. Собрать 5×5 референсы из актуального рисунка. В таблице каждой партии записать позицию, ID, имя, подтип, сокращённое описание и путь референса. Распределить партии между GPT‑6 Luna (max). Проверять референс и результат по одному объекту, перегенерировать визуально неверные или повреждённые ячейки и сохранить список принятых.
3. Для принятых ID заменить `assets/top-down/items/magic/*.png`. Увеличить версию manifest до `1.5.92`, добавить тонкий forwarder, обновить README и точные ожидания тестов релиза. Отметить происхождение рисунков в паспорте. Проверить неизменность остальных PNG и идентификаторов в индексе.
4. Сверить точный набор изменённых PNG, прозрачность, размер и уникальность пикселей по всему каталогу. Запустить `node --test tests/*.test.mjs`, проверку синтаксиса JS, JSON, `git diff --check`, просмотреть diff, сделать commit и push в `lich_branch`.
